# TANEM — Shablon For Only Masters

Чистая базовая версия сайта мастера TANEM.

## Что уже зафиксировано

- актуальный визуальный стиль и цветовая политика;
- мобильная и desktop-механика;
- галерея и lightbox;
- услуги и варианты цен;
- отзывы;
- блок «О мастере»;
- визит и запись;
- анимации и scroll-поведение;
- адаптив;
- hair-механика главного экрана;
- сохранённая, но пока не подключённая к правилам механика палитры для nails.

## Что специально отсутствует

В репозитории нет данных конкретного мастера: имени, города, телефона, услуг, цен, отзывов, фотографий, ссылок записи и аналитики.

Все клиентские поля находятся в `site-data.mjs` и сейчас пустые.

## Чистая структура

- `app/master-template.tsx` — основная механика сайта;
- `app/template.css` — один канонический CSS вместо цепочки старых patch-файлов;
- `public/template-runtime.js` — один runtime-файл;
- `site-data.mjs` — пустые данные;
- `scripts/validate-site.mjs` — проверка структуры;
- `tests/template.test.mjs` — базовые тесты.

Следующий этап — правила разных типов мастеров и сценарии «есть / нет».
