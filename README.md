# TANEM — чистый шаблон мастера

Чистая базовая версия шаблона TANEM для мастеров. Клиентские данные, фотографии, услуги, отзывы, контакты и ссылки в репозитории не хранятся.

Этот репозиторий фиксирует актуальный визуал и механику. Логика разных типов мастеров и правила заполнения будут добавляться следующими этапами.
